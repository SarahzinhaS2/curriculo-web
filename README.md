# Currículo Web

Site de currículo pessoal desenvolvido por mim para apresentar minha formação, cursos, habilidades, experiência profissional e projetos.

O projeto também foi desenvolvido como uma forma de praticar meus conhecimentos em Front-end, principalmente HTML, CSS e JavaScript.

## Sobre o projeto

O site possui uma apresentação inicial e um menu de navegação com diferentes seções do currículo:

- Informações Pessoais
- Formação Acadêmica
- Cursos
- Contato
- Projetos
- Experiência Profissional
- Habilidades

As seções são exibidas através de botões, permitindo navegar pelo conteúdo sem precisar criar uma página diferente para cada parte do currículo.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Desenvolvimento

### HTML

O HTML foi utilizado para estruturar todo o conteúdo do currículo, incluindo:

- Cabeçalho
- Apresentação
- Menu de navegação
- Seções do currículo
- Listas de habilidades
- Links para GitHub, LinkedIn e Figma

### CSS

O CSS foi utilizado para criar o visual e a organização do site.

Alguns recursos utilizados:

- Flexbox
- Media Queries
- Animações com `@keyframes`
- Pseudo-classe `:hover`
- Pseudo-elemento `::after`
- Background com imagem
- Bordas e bordas arredondadas
- Sombras
- Ajustes de tamanho e espaçamento
- Layout responsivo para dispositivos móveis

Também foram utilizadas diferentes fontes para títulos e textos, como `Playfair Display` e `Open Sans`.

### JavaScript

O JavaScript foi utilizado para controlar a interação do site, principalmente na exibição das seções do currículo e no funcionamento dos botões de navegação.

## Responsividade

O site possui uma versão adaptada para telas menores através de uma `@media query` para dispositivos com largura de até 768px.

Nessa versão, tamanhos de fontes, espaçamentos, cabeçalho, botões e seções são ajustados para facilitar a visualização em celulares e outros dispositivos menores.
